# 📱 Mobile Sales Analysis Dashboard — Power BI

## 📊 Project Overview

This project is an **interactive Mobile Sales Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard provides an interactive overview of mobile sales performance across different **months, cities, brands, mobile models, payment methods, customer ratings, and days of the week**.

## 🎯 Project Objective

The main objective of this project is to transform raw mobile sales data into an interactive business dashboard that can help users:

- Monitor overall sales performance
- Analyze sales trends over time
- Compare different mobile brands and models
- Understand city-wise sales performance
- Analyze customer ratings
- Understand preferred payment methods
- Identify sales patterns across different days
- Compare quantity sold and transaction performance

---

## 🗂️ Dataset

**Dataset:** Mobile Sales Dataset Excel File

The dataset contains mobile sales-related information used to perform sales and customer analysis.

The raw dataset was imported into Power BI and prepared using **Power Query** before creating the dashboard.

## 🧹 Data Cleaning & Transformation

The dataset was prepared using **Power Query** before building the dashboard.

The major data preparation steps included:

- Removing duplicate records
- Changing incorrect data types
- Replacing values where required
- Handling blank/null values
- Creating custom columns
- Transforming the dataset into a suitable format for analysis

These steps helped improve the consistency and quality of the data before visualization.

---

## 🧮 DAX & Measures

DAX measures were created in Power BI to calculate important business metrics used throughout the dashboard.

The dashboard includes measures for metrics such as:

- Total Sales
- Total Transactions
- Total Quantity
- Average Price
- Other analytical calculations used in the visualizations

These measures allow the dashboard to dynamically respond to filters and slicers.

---

## 📈 Dashboard Features

The dashboard contains multiple interactive visualizations.

### 🔹 KPI Cards

The dashboard displays key performance indicators including:

- **Total Sales**
- **Total Transactions**
- **Average Price**
- **Total Quantity**

These KPIs provide a quick overview of overall business performance.

### 🔹 Sales by City

A map visualization is used to analyze the geographical distribution of sales and identify cities contributing to sales performance.

### 🔹 Monthly Quantity Analysis

A line chart shows quantity sold across different months, helping identify monthly trends and fluctuations.

### 🔹 Customer Ratings

Customer ratings are visualized to understand the distribution of customer satisfaction across different rating levels.

### 🔹 Payment Method Analysis

A donut chart displays transactions based on different payment methods such as:

- UPI
- Debit Card
- Credit Card
- Cash

### 🔹 Brand Performance

A table provides a comparison of brands based on:

- Total Sales
- Total Quantity
- Total Transactions

### 🔹 Mobile Model Performance

A bar chart compares total sales across different mobile models.

### 🔹 Sales by Day

A day-wise analysis helps identify sales patterns across different days of the week.

## 🎛️ Interactive Filters
